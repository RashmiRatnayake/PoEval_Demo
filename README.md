# PoEval: Trust Before Immutability

### An Interactive Demonstration of ML-Driven Pre-Consensus Trust Evaluation for Permissioned Blockchain-Based IoT Data Marketplaces

## Overview

This repository contains the implementation and interactive demonstration of **Proof of Evaluation (PoEval)**, a machine learning (ML)-driven, pre-consensus trust evaluation framework designed to enhance data trustworthiness in permissioned blockchain-based Internet of Things (IoT) data marketplaces.

## Interactive Demonstration

The demonstration provides an interactive environment for exploring how distributed trust evaluation influences data admission in permissioned blockchain systems.

Through the visualization dashboard, users can observe:

- Incoming IoT sensor measurements and their submission status.
- Independent trust evaluation outcomes generated by ML evaluator nodes.
- Quorum-based aggregation of evaluator decisions.
- Acceptance or rejection of submitted data.
- Changes in blockchain state following successful data admission.

The demonstration highlights the distinction between conventional blockchain workflows, where transaction validity does not necessarily imply data correctness, and PoEval's trust-aware workflow, where submitted data undergo explicit evaluation before immutable storage.

## Research Contributions

PoEval demonstrates how ML-driven pre-consensus evaluation can strengthen data integrity in permissioned blockchain-based IoT marketplaces. Its principal contribution is the integration of distributed, data-centric trust assessment into the ledger admission process, rather than relying exclusively on traditional consensus mechanisms.

The prototype illustrates how this approach can reduce the inclusion of untrustworthy data, improve transparency in admission decisions, and support more reliable downstream applications that consume blockchain-recorded IoT measurements.

## Research Context

PoEval is motivated by the need for trustworthy data management in blockchain-integrated industrial IoT environments, where inaccurate or malicious measurements can affect downstream analytics, automated decision-making, and data marketplace reliability.

The project demonstrates an approach toward **trust-aware blockchain infrastructure**, in which immutability preserves evaluated records rather than indiscriminately preserving submitted data.
